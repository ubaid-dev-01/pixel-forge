# PixelForge brand

Elite visual identity for a professional image & video restoration platform.

## Concept

**Pixels → Reconstruction → Precision**

The mark is a modular geometric object: a solid forged body on the left, reconstructing modules on the right, joined by a teal precision weld. At distance it reads as one symbol; up close the engineering becomes visible.

## Colors

| Token | Hex | Use |
| --- | --- | --- |
| Deep Navy | `#0C1127` | Primary text, dark surfaces |
| Deep Blue | `#011F55` | Logo body, depth |
| Primary Blue | `#0B3F78` | Reconstruct modules |
| Teal Blue | `#1E82A2` | Accent / weld / CTAs |
| Off White | `#FDFCFA` | Light surfaces |

Controlled gradient (optional only): Deep Blue → Teal Blue. Flat color must always work alone.

## Typography

- Display / wordmark: **Clarity City** (600), tracking ≈ `-0.03em`
- Body / UI: **Clarity City** (400 / 500 / 600)
